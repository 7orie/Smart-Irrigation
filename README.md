#  Dynamic Smart Irrigation System (MVP)

An interactive, real-time simulation dashboard for smart irrigation management built using Python, Streamlit, and Pandas.

##  Key Features

1. Dynamic Zone Customization: Define any number of farm zones, crop types, and distances.
2. Automated & Manual Simulation: Real-time logic for soil moisture, pH levels, and distance-weighted water consumption.
3. Smart Alerting System: Instant notifications for extreme dryness or critical pH deviations.
4. RTL UI Friendly: Fully optimized interface layout for Arabic text readability.

##  Tech Stack

* Python
* Streamlit
* Pandas
